# Quick Start Guide - Visual Simulation

## Get Started in 3 Steps

### Step 1: Install Flask

```bash
pip install Flask
```

### Step 2: Run the Simulation

```bash
make simulate
```

Or manually:
```bash
python3 simulator/simulate_web.py
```

### Step 3: Open Your Browser

Navigate to: **http://localhost:5000**
